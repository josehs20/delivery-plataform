# 09 — Prova de Entrega

## 1. Objetivo

Comprovar que a mercadoria foi entregue ao destino informado.

## 2. MVP

A prova de entrega deve conter:

- nome do recebedor;
- fotografia;
- latitude;
- longitude;
- data/hora;
- observação opcional.

## 3. Regras

- A prova deve estar vinculada a uma única entrega.
- O arquivo deve ser armazenado com referência segura.
- O evento de conclusão deve possuir vínculo com a evidência.
- Após conclusão, a prova não deve ser substituída silenciosamente.
- Correções administrativas devem ser auditadas.

## 4. Offline

A captura de foto e dados da prova deve funcionar offline.

O arquivo e metadados devem ser persistidos localmente até sincronização bem-sucedida.

## 5. Futuro

Preparar extensibilidade para:

- assinatura;
- PIN;
- QR Code;
- barcode.

Esses recursos não fazem parte do MVP.
