# API Contracts — V6

Esta pasta define o contrato REST entre o backend Laravel e os aplicativos Flutter.

Fonte de verdade: `/docs`, modelo de domínio e modelo de dados.

Sequência recomendada:
1. visão geral;
2. autenticação;
3. comércio;
4. motoboy;
5. consultas;
6. entregas;
7. ofertas e contrapropostas;
8. pagamentos;
9. localização;
10. sincronização offline;
11. notificações;
12. evidências;
13. administração;
14. erros, idempotência e concorrência;
15. segurança;
16. testes;
17. mapa de implementação;
18. diretrizes OpenAPI.

O backend Laravel é a fonte de verdade para estados, valores financeiros, autorização, concorrência e regras críticas.
