# Implementation Baseline

Este diretório contém o material necessário para iniciar a implementação sem fingir que as regras de negócio já foram programadas.

## Incluído

- OpenAPI;
- contratos de DTO;
- baseline de migrations;
- rotas Laravel;
- controllers esqueleto;
- enum de DeliveryStatus;
- sequência de implementação.

## Importante

Os controllers que retornam `501 NOT_IMPLEMENTED` são scaffolding deliberado. Eles não representam funcionalidades concluídas.

A próxima implementação deve substituir cada endpoint por Use Cases reais, transações, autorização, eventos e testes conforme os `.md` e `.mdc`.
