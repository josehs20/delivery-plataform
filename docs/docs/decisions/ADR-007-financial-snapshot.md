# ADR-007 — Snapshot financeiro da contratação

## Status

Accepted

## Decisão

No momento em que a contratação da entrega for efetivada, os valores relevantes deverão ser congelados como snapshot.

O snapshot inclui, quando aplicável:

- preço calculado;
- preço ofertado;
- contraproposta vencedora;
- valor contratado;
- comissão;
- custos conhecidos do PSP;
- valor previsto ao motoboy.

Alterações futuras nas regras de preço não alteram contratos já realizados.
