# ADR-011 — Primary Keys

## Status

ACCEPTED FOR MVP

## Decision

Use UUID primary keys (stored as CHAR(36)/VARCHAR in MySQL) generated by the application/database consistently across the backend.

## Rationale

- Suitable for distributed/offline-generated references.
- Avoids exposing sequential identifiers.
- Works naturally across API, synchronization and mobile caches.
- Compatible with Laravel/MySQL.

## Rule

All tables use UUID PKs unless a specific infrastructure table has a documented exception.
