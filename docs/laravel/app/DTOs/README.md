# DTOs

Os DTOs do backend devem representar comandos e dados de leitura.

Exemplos:
- CreateDeliveryData
- UpdateDeliveryData
- AcceptDeliveryData
- CreateCounterOfferData
- FailDeliveryData
- CompleteDeliveryData
- LocationPointData
- SyncOperationData

A implementação concreta deve seguir `docs/contracts/30-dto-contracts.md`.
