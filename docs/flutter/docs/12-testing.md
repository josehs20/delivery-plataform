# Flutter — 12. Testes

## Unitários

- cálculo de apresentação de preço;
- mapeamento de estados;
- validações;
- sync queue;
- retry;
- idempotência local;
- regras de formulário.

## Widget tests

Testar estados críticos:

- loading;
- vazio;
- erro;
- offline;
- sincronizando;
- sucesso.

## Integration/E2E

Cobrir pelo menos:

- login;
- criação de entrega;
- oferta/aceite;
- contraproposta;
- coleta;
- prova de entrega;
- falha;
- devolução;
- sincronização offline/online.

## Regra

Não considerar uma feature concluída apenas porque a tela funciona manualmente. Ela deve possuir testes proporcionais ao risco.
