# Flutter — 11. Segurança

## Regras

- Não hardcodar segredos.
- Não armazenar senha localmente.
- Usar armazenamento seguro para tokens/sessão conforme estratégia.
- Evitar logs de dados pessoais e tokens.
- Validar deep links e conteúdo remoto.
- Não considerar o aplicativo como ambiente confiável para autorização.

## Documentos/fotos

Arquivos temporários e evidências devem respeitar a política de retenção do projeto. Limpar cópias temporárias após sincronização bem-sucedida quando não forem mais necessárias.

## Privacidade

Explicar uso de localização e solicitar somente permissões necessárias.
