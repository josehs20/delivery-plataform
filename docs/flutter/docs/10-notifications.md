# Flutter — 10. Notificações

## Push

Registrar token do dispositivo no backend de forma segura e associada ao usuário/dispositivo.

## Eventos

A UI deve reagir a eventos de push/WebSocket recarregando o estado oficial ou aplicando somente dados confiáveis do payload.

## Duplicidade

Uma notificação repetida não deve duplicar uma entrega nem alterar estado de domínio por si só.

## Permissões

Solicitar permissões de notificação conforme UX e plataforma. Explicar ao usuário quando necessário.
