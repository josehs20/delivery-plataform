# Flutter — 13. Performance e Acessibilidade

## Performance

- evitar rebuilds desnecessários;
- paginação de listas;
- compressão consciente de imagens;
- não manter tracking agressivo em background;
- medir uso de bateria e rede;
- evitar carregar histórico inteiro.

## Acessibilidade

- tamanhos e contrastes adequados;
- labels semânticos;
- áreas de toque suficientes;
- mensagens de erro claras;
- não depender apenas de cor para indicar estado.

## Offline UX

O usuário deve saber claramente quando um dado foi:

- salvo localmente;
- sincronizado;
- aguardando sincronização;
- rejeitado pelo servidor.
