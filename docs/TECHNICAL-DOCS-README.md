# Documentação técnica do projeto

A documentação está dividida em três camadas:

```text
/docs
  → produto e domínio, fonte de verdade

/laravel/docs
  → implementação backend

/flutter/docs
  → implementação mobile
```

Os próximos artefatos são as regras `.mdc` de cada tecnologia. Elas deverão ser derivadas desta documentação, sem duplicar ou contradizer as regras de produto.
